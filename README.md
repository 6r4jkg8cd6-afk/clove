# CLOVE · 太阳系观测档案

一个悬浮在银河系中的互动太阳系。使用原生 JavaScript、Three.js 与程序化生成的银河背景构建，所有行星贴图已内嵌，**完全离线、双击即可运行**。

## 网页地址

- 公网访问：**https://6r4jkg8cd6-afk.github.io/clove/**
- 本机访问：**http://localhost:4173/clove/**
- 备用地址：**http://127.0.0.1:4173/clove/**
- 本地启动：双击 `启动CLOVE.bat`，或在终端执行 `node server.js`。
- 直接打开 `index.html` 也可以浏览，但推荐使用上述地址，以获得完整的本地服务器体验。
- GitHub Pages 使用 `main` 分支根目录直接发布，无需构建步骤。

## 打开方式

1. 打开上面的网页地址，或直接双击 `index.html`（推荐 Edge / Chrome）。
2. 等待欢迎页右下角出现 `SYSTEM READY`（首次加载约需数秒，取决于设备性能）。
3. 点击 **进入观测**，或按 `Enter` / `Space` 进入。
4. 想直接开始行星巡游，可点击 **自动巡游**。

服务端为零依赖的 Node.js 静态服务器；不需要安装任何 npm 包。

## 欢迎页

首次打开会停留在欢迎界面。左侧呈现欢迎语、行星数量与观测入口，右侧实时渲染一只缓慢运转的太阳系与银河背景。资源加载期间按钮保持禁用，并显示当前载入阶段；就绪后按钮点亮。

## 交互地图

- **拖拽**：环绕观察。在行星视角下，镜头始终跟随行星公转。
- **滚轮 / 双指捏合**：推进、拉远。向行星推进到一定距离会自动进入「近地」视角。
- **点击行星 / 左侧索引**：锁定行星，进入它独立的动态观测视角。
- **行星 / 近地**：切换轨道近观与表面低轨视角；第二次点击已选行星也可直接进入近地。
- **自动巡游**：每 9 秒自动前往下一颗行星。
- **时间滑块 / ±**：时间流速 0×–4×；设为 0 时轨道暂停，恒星表面仍在燃烧。
- **标签**：显示 / 隐藏行星世界标签。
- **沉浸模式**：`H` 隐藏所有界面，只留下行星与银河；`ESC` 返回。
- **键盘**：`←` / `→` 切换行星，`1`–`8` 直接跳转，`Space` 开关巡游，`L` 开关标签，`ESC` 返回全景。
- **环境音**：右上角圆形按钮，生成式深空低频音景（默认关闭）。

## 场景细节

- 8 颗行星使用 1536×768 高清表面贴图；地球额外使用法线贴图、云层与由高光分布反推的海洋粗糙度贴图，海洋因此具有柔和而真实的反射。
- 岩石行星使用由表面亮度构建的凹凸映射，配合更高细分球体，在近地视角呈现微地形起伏。
- 每颗行星拥有独立的镜头方位、俯仰角、行星尺度与慢速漂移参数；每次锁定都会从向阳面切入，避免看到纯黑夜面。
- 土星使用真实环带纹理，并在环面着色器中计算行星投射的阴影。
- 大气层使用向阳面/晨昏线混合着色，边缘出现蓝色散射与暖色日落过渡。
- 太阳使用贴图 + 实时噪声着色器，带有分层日冕、星芒、脉冲光晕与缓慢自转。
- 银河背景为 Canvas 程序化绘制：双臂对数螺旋、尘埃带、核心星团、星云与镜头光晕，并根据指针和镜头产生视差。
- 3D 星场、小行星带、柯伊伯带、彗星与伽利略卫星等作为空间参照；进入行星视角后自动收起近景小行星带，保持观测画面干净。
- 半透明资料卡包含：实时轨道相位、日心距离、温度区间、直径、周期、卫星数与观测亮点。
- 响应式布局：桌面为左右仪表盘，移动端切换为顶部行星索引与底部资料抽屉。

## 说明

- 轨道半径、行星大小与距离并非真实比例，为视觉叙事做了压缩；资料卡中的物理数据取自公开天文资料。
- 首次加载会解码内嵌高清贴图与生成银河背景；资源完全内嵌，不需要联网。
- 需要支持 WebGL 的现代浏览器。建议在独立 GPU 或较新的集成显卡上以 1440×900 及以上分辨率观看。
- 刷新页面即可重新看到欢迎界面。
